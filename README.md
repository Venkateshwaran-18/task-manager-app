# Task Manager App (React + .NET)
A full-stack Task Management Application built using React (Frontend) and ASP.NET Core Web API (.NET 10) with JWT Authentication and SQL Server.
🚀 Features
🔐 User Authentication (Register & Login)
🔑 JWT-based Authorization
👤 User-specific task management
✅ Create, View, Complete, Delete Tasks
📡 RESTful API with ASP.NET Core
⚛️ React frontend with Axios integration
🗄️ SQL Server with Entity Framework Core (Code First)
📄 Swagger API documentation
🏗️ Tech Stack
Frontend
React
Axios
JavaScript
Backend
ASP.NET Core Web API (.NET 10)
Entity Framework Core
JWT Authentication
BCrypt for password hashing
Database
SQL Server
